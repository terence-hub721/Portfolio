# Terence Portfolio (React)

This project is a React.js conversion of the existing portfolio design.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Notes

- The React app entry point is `src/App.jsx`.
- Styling is defined in `src/styles.css`.
- The original HTML file is preserved as `terence_portfolio.html`.
